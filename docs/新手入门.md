# 新手入门

## 你是谁，从哪开始

### 场景 1：我想做系列动画，只有我一个人

从 `character-ip` 开始，别从生成开始。

1. `character-ip` —— 给角色建档案：参考图、三视图（含背面）、一致性规则。这是整条管线的地基，没有它后面全部在抽卡。
2. `agnes-video-prompt` —— 用 A/B 实测过的长提示词写法出片。
3. `ep-qa` —— 成片体检，过了再进下一集。

### 场景 2：已经有角色，但一换镜头就变脸

直接调 `character-ip`，重点看三件事：

- 参考图是叠加关系：角色 ref 保身份，风格 ref 保色板
- 每个镜头都挂 ref，背影镜最易漏
- Character Sheet 裁单张喂，清掉字母标注

### 场景 3：提示词写了十几版都在抽卡

`agnes-video-prompt` 里有 A/B 实测结论：正式生产用三段式长提示词，别用一段式短提示词赌运气。先读 [实测判据.md](../knowledge/实测判据.md) 第二节，再动手。

### 场景 4：片子做完了，不确定能不能发

`ep-qa` 机器体检：画幅、时长、音轨、响度、黑帧、帧率、镜头密度、系列一致性。它只报可测量的交付事实，**不判审美**——审美是你的活。

### 场景 5：收藏夹里一堆参考，一个都没用上

成套走：

1. `x-bookmarks-mining` / `content-research-board` —— 把收藏和平台内容变成结构化看板
2. `behance-research` + `behance-replicate-run` —— 找对标、拆解、跑通复刻
3. `studio-site-teardown` —— 把同行网站拆成定位话术 + 站点结构

### 场景 6：新 AI 工具又出了，要不要跟

`new-tool-triage` 四选一：只用 / 扩展 / 包装 / 抄（抄必署名）。判据只有一条：**能不能离「一个具体的人愿意付钱」更近**。不能 → 放下。

### 场景 7：今天不知道该干什么

`frame` —— 开工简报：读你的任务板、重排优先级、给今天的三个动作。收工时再跑一次，自动归档今天做了什么。

## 使用习惯

- **不确定调哪个 skill 时，说 `/ops + 你的处境`**，让制片主任派活。
- **一次一个工位。** 生产没完成不谈质检，质检没通过不谈发布。
- **这些 skill 只报事实，不替你做审美判断。** 最终验收永远是人的活。
- skill 之间靠文件交接，输入输出都落本地文件，可追溯。

## 常见问题

**Q：需要付费的 AI 服务吗？**
管线里有多条通道，部分提供免费额度。各 skill 会标注通道和成本，先看再跑。

**Q：不用 Obsidian / 不用 Claude Code 能用吗？**
能。skills 是 Markdown 文件，任何支持 Agent Skills 的工具都能装（WorkBuddy、豆包、Codex 等）。带 Obsidian 字样的两个 skill 是可选工位。

**Q：为什么有的 skill 提到「本地管线」？**
`drama-claw-hermes` 属于进阶工位，依赖本地部署的开源视频管线。跳过它不影响其他 25 个 skill。

### 场景 8：每次开会话都要重新解释一遍项目背景

`universal-brain` —— 问你三个问题，把任意 Markdown 文件夹变成跨平台大脑：000- 入口页（aliases 用口语词）+ 三层记忆（machine/human/global）+ 链注册表。已有 Obsidian 库的走「体检」模式，只补层不推翻。方法论全文见 [通用大脑](通用大脑.md)。
