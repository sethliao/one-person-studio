# 实测判据库

> 这条管线跑过的片、踩过的坑、得出的定论。每一条都来自真跑过的片（不是查来的说法）。
> 排序原则：**能直接改变你下一次 prompt 的放前面**。

## 一、任务性质决定成败（最上面那条）

> **风格迁移（「像那一类」）AI 很行；角色还原（「就是那一个」）不行。**

这不是参数问题，是性质问题。分工因此固定：

| 层 | 交给谁 | 为什么 |
|---|---|---|
| 画风 / 场景 / 氛围 / 光 | AI | 「像那一类」是它的强项 |
| 角色表演本体 | 3D（Blender 渲染） | 「就是那一个」要的是身份锁定 |
| 叙事结构 / 节奏 | 自己写 | 模型不懂你的故事 |

由此推出的高价值落点：**B-roll 和讲解镜头本来就没有角色**——正好绕开 AI 唯一的硬伤。六类能直接跑的：微缩空镜、材质道具特写、光烟水尘、纸片拼贴讲解、强关联转场、绿幕片头。

**反例**：信息图 / 图表 / 文字卡不要交给视频模型——它会写错字且不可改。这类走 HTML 渲染成视频：可改、可复用、可重跑。

## 二、角色一致性（唯一有成套解法的一段）

- **两张参考图是「叠加」关系**：角色 ref 保身份 + 风格 ref 保色板，互不干扰。参考图锁的是色板（画风指纹）——想换风格就换风格 ref，不用动角色 ref。
- **还原度 ≈ 参考图质量 × 角色辨识度 ÷ 改动幅度**——三项都能人为改善，别认命。
- **Character Sheet 是非正面视角的唯一解**：3D 本体转一圈渲 4 个视角，必须含背面。别把整张 sheet 当一张图喂——按镜头裁单张，并清掉字母标注/箭头等 sheet 残留，否则模型会照画。实测对照：给了背面参考的背影镜成立，没给的直接崩。
- **一致性公式（实测管用）**：`Maintain the character with <逐条特征> from the first frame` → 6 秒镜头六帧零漂移（兜帽/爪垫/腮红全对），且模型会自己覆盖参考图的杂背景。
- **有角色就必须挂 ref，一镜都不能省**——背影镜最易漏，漏了就会凭空长螺旋发/多一截脖子/换布景。
- **场景 prompt 写死相机语言**：`camera is inside the set, we never see the outside walls`——否则盒壁会露出来。
- **姿势漂移 ≠ 身份漂移**——一个改 prompt，一个改方案，判断时别混。

## 三、控制手段

**首帧软锚定**（同 prompt 同首帧 A/B，量化为第 0 帧对参考图的 PSNR）：

| 模式 | 第 0 帧对齐 | 结论 |
|---|---|---|
| 默认 | 12.88 dB | 只当参考，构图会飘 |
| 锚定首帧 | **19.28 dB**（+6.4） | 软锚定：构图保住 |
| 锚定首尾 | 19.16 / 20.18 dB | 两端都锚得住 |

- 软锚定不是硬锁帧（硬锁在 30dB 以上）；锁首帧保构图、不保细节丰富度。
- **验首尾帧必须抽 t=0 / t=end——等距采样会误判**（用 1/3 处的帧去比首帧，会得出「没对上」的错误结论）。

**文字类目标（logo/字标）**：守得住字形，但会自作主张加效果。prompt 显式写：`flat matte solid ink only, no gloss / chrome / gradient / highlight`。

## 四、出片安全过滤（静默坏，最难查）

它会静默挡掉整条动态，只报 `error_code=0 DANGEROUS`，不告诉你是哪句。实测中招词 → 替换：

| 别用 | 换 |
|---|---|
| dying | rests quietly |
| final movement | calm and peaceful |
| go completely still | end of a long day |

判据：一条片子**别的都正常但就是不出**，先怀疑这层。

## 五、「好看」是可以拆开的

四个变量：**分辨率 / 运动量 / 光比 / 构图密度**。四条全调错（低分辨率+刀切静帧+平光+道具堆满）= 判「不好看」；要给人看的片子，先把画面做对，再谈省。

白嫖技巧的反向应用：**节奏在剪辑里，不在模型里**——静帧推镜 + 二次构图 crop + 硬切，素材观感放大 1.4 倍，成本零增加。

## 六、音频与卡点

- **卡点剪辑 = 先算再剪**：节拍检测 → 按拍装配。凭感觉排的转场实测偏了 +273 / −381 / −108 ms。
- 拼接要量化到整数帧，否则累积帧漂移；估周期不能用「搜索命中率最高」（会挑到真周期的约数）。
- 外部音乐轨要显式配：路径、起点、增益、淡入淡出、环境音闪避。

## 七、质检阈值（实测标定，不是拍脑袋）

- **静音判定：−50dB**。（拍脑袋设 −40 被纠正过——阈值必须实测标定。）
- 指标全员同值 = 指标没在工作；错误检查比没检查更糟——审计器要先在坏样本上验过。

## 八、长提示词 vs 短提示词（A/B 实测）

| | 短（159 字） | 长（872 字） |
|---|---|---|
| 结构 | 一段话说完 | 三段式 + 逐段正向/反向 |
| 角色一致性 | 漂移 | **明显更稳** |
| 适用 | 快速草稿 | 正式生产 |

注意例外：部分通道反过来偏好短提示（≤300 字），换通道时先跑 A/B，别拿旧经验硬套。
