# Content Strategy for Animation IP (WorkBuddy 适配版)

Plan content for original character/IP animation projects so each piece compounds into audience growth and a durable fan base.

> 迁移说明：改写自通用 `content-strategy`(v2.1.1)。原版面向 B2B SaaS 产品营销(SEO/关键词/leads/sales)。**已改写为原创动画 IP 创作者方法**：提取通用精华(Searchable↔Shareable、pillars、priority scoring、60/30/10、Create Once Distribute Twice、ORB)，去掉 SEO/Ahrefs/sales-call/headless-CMS 等无关内容。用户真实范例见 `Wiki/小厚先生/内容策略.md`。

## Frame: 破圈 vs 沉淀 (the IP analog of Searchable vs Shareable)

Every piece serves one of two jobs — prefer a balance, weighted by goal:

- **破圈 Shareable** — creates *new* reach. Novel angle, character-in-culture moment, catchy hook, viral format, trend-binding, 爆款公式. Spreads the IP to people who don't follow yet. → good for 抖音/TikTok/小红书 discovery.
- **沉淀/涨粉 Searchable-ish** — deepens relationship with existing fans + keeps the character "ownable". Consistent character series, 角色世界观, 幕后/creator-story, 表情包合集, 私域长文. → 公众号/私域/深度粉.

For an original IP, the durable asset is the **owned fan relationship + character identity**, not rented-platform followers (see distribution reference: ORB funnel).

## Before planning: gather IP context
- Which IP (小厚先生 / 熊猫莫莫 / Paikea)? Read its hub `Projects/<IP>/<IP>.md` + `Wiki/<IP>/` for 角色人设 / 世界观 / slogan.
- If a per-IP `内容策略.md` exists (e.g. `Wiki/小厚先生/内容策略.md`), read it and build on it — don't re-derive.
- Goal: what's the current objective? (涨粉 / 破圈单条 / 私域沉淀 / 商业联名 / 周边 / 海外分发)

## Content Pillars (角色 IP 的核心系列)
Identify 3-5 series/"pillars" the character can repeatedly produce from — the character's own emotional territory.
- **人设情绪系列** (e.g. 打工厚 / 社恐厚 / 恋爱厚 / 催婚厚 / 反骨厚)
- **世界观故事系列** (角色关系、配角、世界观事件)
- **互动共创系列** (投票、提问、粉丝二创翻牌)
- **幕后/创作者系列** (诞生故事、创作过程 — 深度粉最爱)

Each pillar spawns clusters; interlink so fans can traverse the character.

## 爆款公式 (borrow from existing IP strategy)
Real formulas from `Wiki/小厚先生/内容策略.md`:
- **情绪共鸣型**：`场景痛点 + 角色反应 + 金句总结`（打工/社恐/催婚）
- **反差萌型**：`软萌外表 + 硬核内心 + 意外结局`
- **互动参与型**：`提问/投票 + 粉丝共创 + 官方翻牌`
Design per-IP versions of these.

## Platform matrix & calendar
Map platforms by priority (frequency × goal), e.g. (from 小厚先生):
| 优先级 | 平台 | 形式 | 目标 |
|---|---|---|---|
| P0 | 小红书 | 单格/四格漫画 + 9:16 金句海报 | 涨粉+转化 |
| P1 | 公众号 | 长图文(角色故事/幕后/表情包) | 私域沉淀 |
| P2 | 抖音 | 15-30s 短视频/动态漫画 | 破圈 |
| P3 | B站 | 1-3min 小剧场 | 深度粉 |
| P4 | YouTube/IG/TikTok | 双语短视频 | 海外分发 |
| P5 | X/微博 | 金句帖 | 互动 |

Balance the **calendar 60/30/10**: ~60% consistent series (predictable), ~30% 破圈/shareable bets, ~10% experiments/new formats.

## Prioritize content ideas (scoring)
Score each idea on the four factors:
1. **IP 契合 + 人设强化 (40%)** — does it deepen the character & what fans expect?
2. **内容-市场 fit (30%)** — fits a pillar; does it hit a current 痛点/梗/情绪?
3. **破圈/传播潜力 (20%)** — hook, trend-fit, shareability, 二创 potential
4. **资源成本 (10%)** — can you produce it with current tools/media assets?

| Idea | 契合(40%) | Fit(30%) | 传播(20%) | 成本(10%) | Total |
|------|----------|---------|----------|----------|-------|
Rank; make top-scoring first.

## Create Once, Distribute Twice (IP version)
One flagship piece, then reformat across platforms — not a fresh piece per platform.
- A single 漫画/短片/歌曲 → derive: 小红书图文、金句海报、TikTok hook clip、IG carousel、X 单句金句、公众号幕后长文.
- **Build distribution hooks at creation time**: sections that stand alone as posts, pull quotes to graphic-ify, bilingual-ready dialogue.
- Route by **ORB**: Borrowed (collabs/二创生态) → Rented (social platforms, you don't own the algo) → Owned (公众号/email/私域/周边 = durable). Owned is where the IP's value compounds.

**Failure modes**: 撒胡椒面 (no flagship, no repurpose plan); 平台依赖 (all effort on rented land you don't control); 忽略私域 (spend on reach but no owned channel to convert into).

## Output format
When producing a content strategy deliverable:
1. **Pillars/series** (3-5 with rationale, subtopic clusters, how they tie to 人设)
2. **Priority topics** (each: title, 破圈 or 沉淀, format, which formula/pillar, why — audience/竞品 backing)
3. **Platform matrix + calendar split**
4. Optionally a topic-cluster map.
