# universal-brain：通用大脑搭建器

你的任务是给用户搭一个「所有 agent 都能读的大脑」——一个有入口、有分层、有纪律的 Markdown 文件夹。

**核心信念：大脑要人能读，agent 才能用得久。** 大部分人的知识库死掉，不是因为 agent 太笨，是因为结构连人自己都不想维护。你的工作是给一个**人愿意维护**的最小骨架，而不是一个华丽的空城。

---

## 第一步：判断处境

先看用户带来了什么，三选一：

- **空文件夹 / 从零开始** → 走「新搭」流程
- **已有 Obsidian vault 或笔记堆** → 走「体检」流程，不要推翻重来
- **已有但 agent 每次都记不住** → 多半缺入口层或缺纪律，走「补层」流程

## 新搭：问三个问题，生成骨架

只问会改变结构的三个问题：

1. 「这个大脑主要装什么？」（一个项目 / 多个项目 / 全部生活）
2. 「你打算用哪个工具打开它？」（Obsidian / VS Code / 只给 agent 读）
3. 「你嘴上会怎么称呼它？」（用来定 aliases——用户叫「工作台」就别叫 dashboard）

然后生成这套骨架（全部人读得懂，没有任何黑话文件）：

```text
<大脑名>/
├── 000-现在做什么.md      # 唯一入口：现在做哪件 / 到哪了 / 去哪找
├── machine/
│   └── 说明.md            # 每日工作日志，append-only，临时输出不进
├── human/
│   └── 说明.md            # 人读结论与决策，一条决策一页
├── global/
│   └── 铁律.md            # 跨项目记忆，指针化 ≤3KB，细节指向文档
└── chains/
    └── REGISTRY.md        # 链注册表（有 3+ 个常用 skills 后再填）
```

### 入口页模板

```markdown
---
tags: [next, home]
aliases:
  - <用户嘴上的称呼，必须写>
  - 首页
---

# ▶ 现在做什么

## 现在做哪件
- （最多 3 件，标优先级）

## 到哪了
- （每条线一句话状态）

## 去哪找东西
- （3-5 个常用位置，链接必须可点）
```

### 链注册表模板

```markdown
# 链注册表：skills 怎么串成链

## 链：<名字，用口语词>
- 口令：<一句话触发，如「跑一条」>
- 步骤：skill-a → skill-b → skill-c
- 交接：上一步输出文件落在 <run目录>，下一步从那里读
- 门控：<什么条件链提前停止>
```

## 体检：已有 vault 怎么看

按四个检查点过一遍，**每个检查点给「过 / 补」结论，不许推翻重来**：

1. **有没有唯一入口页**——没有就补一个 `000-` 开头的，别在多个 README 之间犹豫
2. **aliases 是不是口语词**——抽查 5 个常用页：用户嘴上说的词，搜得到吗？搜不到 = 补 alias
3. **记忆有没有分层**——日志、结论、铁律混在一个文件里的，帮拆成三层
4. **有没有双真源**——同一个事实两处可写的，指定一处，另一处改指针

## 补层：agent 记不住的原因排查

按命中率排序：

1. **没告诉 agent 入口在哪** → 在 agent 的规则文件（CLAUDE.md / 系统设定）里写死：「每次开工先读 <入口页路径>，收工往 machine/ 追加日志」
2. **入口页过期** → 状态不靠对话靠文件；每次收工刷新入口页，这是纪律不是选项
3. **记忆长成了聊天记录** → machine/ 里出现搜索结果、报错栈、临时路径 → 清出去，只留跨会话有用的结论
4. **事实有两个真源** → agent 读到打架的版本，行为随机 → 消灭双真源

## 交接：给读不了磁盘的平台

网页版 agent（Coze / Kimi / GPTs 等）碰不到本地文件。别硬喂，改「交接包」：把 vault 里当前任务需要的页编译成一份平台中立的 Markdown（去 wiki 双链、去平台专有语法、链接转标准 URL），一次导出，处处能喂。已有 vault 时引导用户装 `ai-handover-pack`。

## 纪律（写进每次生成的说明.md 里）

- **只增量，不重写**——多个会话同时写时，各写各的文件
- **同一事实只有一个真源**——两处可写 = 必然打架
- **记忆要瘦身**——global 层 ≤3KB 指针版，细节指向文档
- **找得到才算存在**——链接不包代码反引号；新页必带口语 aliases

## 完成标准

搭完必须验证三件事，缺一不算完：

1. 用户用嘴上的词搜大脑，能搜到入口页
2. 入口页里每条链接点得动（没有死链、没有反引号包死的链接）
3. 用户能用一句话把入口页路径告诉任意新 agent，并复述收工纪律
