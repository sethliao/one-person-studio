# 《小厚先生》核心设定（必须内化）

**一句话**：3D 黏土 / 乙烯基玩具风格的 chibi 角色，表面呆萌无害，内心倔强反骨。
**Slogan**：厚住，我们能赢。
**受众**：18–35 岁打工人 / 社恐。
**六大情绪系列**：打工厚 · 社恐厚 · 减肥厚 · 恋爱厚 · 催婚厚 · 反骨厚。

## 视觉硬约束（违反即废片）

1. **厚粉唇 #F0A0A0 不可省略** —— 第一辨识特征，任何风格化都不能丢
2. **眼睛 = 黑色竖线 T-bar**，无瞳孔、无高光、不大圆眼
3. **发色固定 #6B4226 巧克力棕**，中分短波浪，有粘土雕塑团块感
4. **服装只有两套**：定稿装（白短袖衬衫＋深灰短裤＋赤脚）／日常装（米色 hoodie＋深棕长裤＋白鞋）
5. **比例**：chibi 头身比 ≈ 1:1，大头小短身，圆润腮帮
6. **材质**：平滑哑光黏土 / 乙烯基，轻微表面凹凸
7. **背景**：默认浅蓝渐变 + 左上柔光棚拍 + 柔和环境光遮蔽阴影
8. **表情变化只靠三处**：眉毛角度 + 眼睛线条疏密 + 嘴唇形态。**不改五官结构。**

## 语气（写台词时）

贱萌 · 治愈 · 反骨 · 互联网嘴替。

- ❌ "加油，你可以的！" → ✅ "行了，今天先厚住，明天再厚住。"
- ❌ "要相信自己呀～" → ✅ "我没事，我装的。"
- ❌ 鸡汤、正能量、励志 → ✅ 共鸣、自嘲、不服气但先忍着

## 格式 C · 图文帖文案

- **标题**：≤ 20 字，要有钩子，不用感叹号堆砌
- **正文**：≤ 200 字，分 2–3 段，口语，可带一个 emoji
- **话题标签**：5 个，混合大词与精准词
- **封面建议**：一句话说明用哪个表情、什么构图

# 协作方式

- 用户给的 brief 通常很短、可能是语音输入（中英粤混杂、有错字）。**按意图理解，别抠字面，别反复确认。**

- 一次给全：分镜 + 提示词 + 可选文案。不要挤牙膏。
