# 扣子工作流蓝图 · 小厚先生短视频生产

> 目标：输入一句 brief，输出「分镜表 + 每镜提示词 + 首帧图 + 视频片段」。
> 不建工作流也能用（靠系统提示词），但建了以后**每次省掉解释成本，且产出格式稳定**。

---

## 节点图

```
[Start]
  输入：主题（string）/ 情绪系列（选填）/ 时长（默认 15s）/ 画幅（默认 16:9）
        │
        ▼
[LLM 节点 1 · 选题]
  角色提示词：你是《小厚先生》编剧。按用户主题，从六大情绪系列里选最贴的一个，
  写一句 ≤15 字的钩子 + 一句 ≤20 字的落点。只输出 JSON。
  输出：{ "series": "...", "hook": "...", "punchline": "..." }
        │
        ▼
[LLM 节点 2 · 分镜]
  角色提示词：把上面的钩子拆成 N 个镜头（15s → 3–5 镜，每镜 2–4 秒）。
  遵守《角色一致性描述》。输出 JSON 数组。
  输出：[ { "no":1, "dur":3, "visual":"...", "camera":"...", "line":"...", "series":"..." } ]
        │
        ▼
[代码节点 · 拼提示词]
  Python：遍历分镜数组，按固定结构拼英文 prompt：
    [角色核心描述] + [动作] + [场景] + [镜头景别] + [光线] + [画幅比例]
  输出：[ { "no":1, "prompt":"...", "dur":3 } ]
        │
        ▼
[批处理节点]
  对每个镜头并行执行：
    ├─ [插件 · 文生图]   prompt → 首帧图（1:1 或按画幅）
    └─ [插件 · 图生视频] 首帧图 + prompt + 时长 → 视频片段
        │
        ▼
[End]
  输出：分镜表 + 提示词 JSON + 图片链接数组 + 视频链接数组
```

---

## 关键配置点

| 位置 | 要设什么 | 为什么 |
|------|----------|--------|
| Start 节点 | 画幅默认 16:9 | Seth 的 GFlow 工作流就是默认横屏，保持一致 |
| LLM 节点 1、2 | 温度 0.7–0.9 | 要创作性；但格式必须靠「只输出 JSON」+ 输出 schema 锁死 |
| 代码节点 | 角色核心描述**硬编码**成常量 | 不要让 LLM 每次重新生成，它一定会漂移 |
| 文生图插件 | 固定同一组种子 / 参考图 | 保证跨镜头角色一致 |
| 图生视频插件 | 每镜时长对齐分镜表 | 否则拼起来节奏乱 |

## 模型选型（2026-09 价格，以官网为准）

节流原则：**首帧图决定成败，视频模型只负责让它动起来** → 图用好的，视频用便宜的。

| 用途 | 推荐 | 单价 | 备注 |
|------|------|------|------|
| 首帧图 | 扣子图像流内置 / Seedream | 免费额度内 | 零配置，先用这个 |
| 首帧图（要更准） | Nano Banana（Google Flow） | 订阅内 | Seth 已有账号 |
| 视频（首选） | 火山方舟 Seedance 2.0 **Mini** | ≈ ¥0.5/秒 @720p | 与扣子同生态，插件原生 |
| 视频（备选） | 阿里百炼 HappyHorse 1.1 | ¥0.54/秒 @720p（优惠价） | 盲测榜第一 |
| 视频（最便宜） | Google Veo 3.1 **Lite** | $0.05/秒 @720p | ≈ ¥0.36/秒 |
| ⚠ 避开 | 即梦 C 端订阅 | ¥1.38/秒起 | 2026 年三连涨价，不划算 |

**一条 15 秒片子的视频成本 ≈ ¥7.5（Seedance Mini）**，比即梦路线省一半以上。
